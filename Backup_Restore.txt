নতুন সার্ভারে ব্যাকআপ ফাইল আপলোড করতে সবচেয়ে সহজ পদ্ধতি scp বা rsync। নিচে বাংলায় ধাপে ধাপে দিলাম।

১. প্রথমে ব্যাকআপ ফাইল খুঁজে নিন

ls -lh /var/backups/isp_billing_*/isp_billing_full_*.tar.gz
২. scp দিয়ে আপলোড (সোজা ও সহজ)

scp /var/backups/isp_billing_YYYY-MM-DD_HHMMSS/isp_billing_full_YYYY-MM-DD_HHMMSS.tar.gz \
  user@NEW_SERVER_IP:/home/user/
যদি SSH port আলাদা হয় (যেমন 2222):

scp -P 2222 /path/to/backup.tar.gz user@NEW_SERVER_IP:/home/user/
৩. rsync দিয়ে আপলোড (বড় ফাইলের জন্য ভালো, মাঝপথে থামলে আবার শুরু করা যায়)

rsync -avP /var/backups/isp_billing_YYYY-MM-DD_HHMMSS/isp_billing_full_YYYY-MM-DD_HHMMSS.tar.gz \
  user@NEW_SERVER_IP:/home/user/
আপনার নতুন সার্ভারের IP, ইউজারনেম, আর কোন ফোল্ডারে রাখতে চান—এগুলো দিলে আমি একদম ঠিক কমান্ড লিখে দেব।

========================================================================

নিচে Restore করার সম্পূর্ণ বাংলা গাইড দিলাম (ফাইল + DB + Apache/SSL + cron সবকিছু):

✅ 1. ব্যাকআপ ফাইল Extract করুন
mkdir -p /restore_tmp
tar -xzf /path/to/isp_billing_full_YYYY-MM-DD_HHMMSS.tar.gz -C /restore_tmp
✅ 2. প্রোজেক্ট ফাইল কপি করুন
rsync -av /restore_tmp/isp_billing /var/www/
✅ 3. ডাটাবেজ রিস্টোর
আগে নতুন সার্ভারে খালি DB তৈরি করুন:

mysql -u root -p -e "CREATE DATABASE isp_billing CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
তারপর SQL ইমপোর্ট করুন:

mysql -u root -p isp_billing < /restore_tmp/db.sql
✅ 4. Apache + SSL কনফিগ ফিরিয়ে আনুন
cp -a /restore_tmp/apache2 /etc/
cp -a /restore_tmp/ssl /etc/
cp -a /restore_tmp/letsencrypt /etc/   # যদি থাকে
✅ 5. Cron jobs রিস্টোর
crontab /restore_tmp/cron_user.txt
sudo crontab /restore_tmp/cron_root.txt
✅ 6. Apache রিলোড
sudo systemctl restart apache2
আপনার সার্ভারের OS বা MySQL ইউজারনেম ভিন্ন হলে বলুন, আমি কমান্ডগুলো আপনার মতো করে সাজিয়ে দেব।
