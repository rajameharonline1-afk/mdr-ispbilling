# ISP Billing Master Scripts 🌐

এটি একটি লিনাক্স-ভিত্তিক অটোমেশন টুলকিট যা ISP সার্ভারের ডাটাবেস ব্যাকআপ, রিস্টোর এবং প্রাথমিক সেটআপের কাজগুলোকে সহজ ও দ্রুত করে তোলে।

## ফিচারসমূহ ✨
* **অটোমেটেড ব্যাকআপ:** একটি ক্লিকের মাধ্যমেই পুরো ডাটাবেস ব্যাকআপ নেওয়া যায়। 💾
* **সহজ রিস্টোর:** প্রয়োজন পড়লে দ্রুত ব্যাকআপ ফাইল থেকে ডাটা রিস্টোর করার সুবিধা। 🔄
* **ফুল সেটআপ স্ক্রিপ্ট:** নতুন সার্ভারে প্রয়োজনীয় এনভায়রনমেন্ট তৈরি করার জন্য কমপ্লিট স্ক্রিপ্ট। 🚀
* **লগিং সিস্টেম:** প্রতিটি কাজের রেকর্ড রাখার ব্যবস্থা। 📋

## প্রয়োজনীয় রিকোয়ারমেন্টস 🛠️
এটি চালাতে আপনার সিস্টেমে নিচের টুলগুলো থাকতে হবে:
* **OS:** Ubuntu/Debian (Linux) 🐧
* **Database:** MariaDB বা MySQL 🗄️
* **Web Server:** Apache বা Nginx 🌐
* **Tools:** `git`, `bash`, `cron`

## ইন্সটলেশন ও ব্যবহার বিধি 🚀

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone [https://github.com/bdidamir/mrd_billing.git](https://github.com/bdidamir/mrd_billing.git)

# ২. প্রজেক্ট ফোল্ডারে প্রবেশ করুন
cd mrd_billing

# ৩. স্ক্রিপ্টগুলোকে এক্সিকিউটেবল করুন
chmod +x *.sh

# ৪. ফুল সেটআপ রান করুন (Root পারমিশন প্রয়োজন)
sudo ./full_setup.sh
