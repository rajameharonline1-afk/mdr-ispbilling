🪝 bKash Webhook দ্রুত রেফারেন্স

ISP Billing System এ রিয়েল-টাইম পেমেন্ট আপডেটের জন্য Webhook কনফিগারেশন গাইড

📋 সারসংক্ষেপ

PGW Callback

উদ্দেশ্য: bKash Portal থেকে পেমেন্ট সম্পন্নতার নোটিফিকেশন

পদ্ধতি: GET (Redirect)

রেসপন্স: HTML (বাংলা)

স্টোরেজ: sms_inbox টেবিল

RTN Webhook

উদ্দেশ্য: বাস্তব-সময় পেমেন্ট নোটিফিকেশন (Webhook)

পদ্ধতি: POST (JSON)

প্রমাণীকরণ: টোকেন হেডার/Query

স্টোরেজ: bkash_rtn_events টেবিল

1️⃣ PGW Callback Endpoint

PGW পেমেন্ট সম্পন্নতা (PGW Payment Completion)

GET
https://YOUR_DOMAIN/api/bkash_pgw_callback.php?paymentID=...&status=success

প্যারামিটার:

প্যারামিটার বিবরণ উদাহরণ
paymentID bKash পেমেন্ট আইডি (প্রয়োজনীয়) pay_20251214123456
status লেনদেন অবস্থা (success/failure) success

প্রক্রিয়াকরণ:

  1. ✓ bKash executePayment API কল করে পেমেন্ট সম্পাদন করে
  2. ✓ লেনদেনের বিস্তারিত sms_inbox টেবিলে সংরক্ষণ করে
  3. ✓ বাংলা HTML রেসপন্স দেখায়
  4. ⏳ Cron job (auto_bkash_apply.php) প্রতি ৫-১০ মিনিটে ইনভয়েসের সাথে ম্যাচ করে এবং প্রয়োগ করে

সফল উত্তর:

<h3>পেমেন্ট সম্পন্ন হয়েছে</h3> <p>ট্রান্স্যাকশন আইডি: TRX20251214000001</p> <p>অ্যামাউন্ট: 1000.00</p>

2️⃣ RTN Webhook Endpoint

রিয়েল-টাইম পেমেন্ট নোটিফিকেশন (Real-Time Notifications)

POST
https://YOUR_DOMAIN/api/bkash_rtn/notify.php

হেডার:

Content-Type: application/json X-Bkash-Webhook-Token: YOUR_SECRET_TOKEN

বিকল্প (Query Parameter):

https://YOUR_DOMAIN/api/bkash_rtn/notify.php?token=YOUR_SECRET_TOKEN

পেলোড উদাহরণ:

{ "eventType": "payment_success", "eventId": "evt_123456", "trxID": "TRX20251214000001", "transactionStatus": "COMPLETED", "amount": 1000.00, "customerMsisdn": "01712345678", "merchantInvoiceNumber": "INV-2025-001" }

প্রক্রিয়াকরণ:

  1. ✓ টোকেন যাচাই করে (Header বা Query)
  2. ✓ JSON পেলোড বিশ্লেষণ করে
  3. ✓ bkash_rtn_events টেবিলে ইভেন্ট সংরক্ষণ করে
  4. ✓ JSON রেসপন্স দেয় (বাংলা মেসেজ সহ)
  5. ⏳ Cron job (bkash_rtn_process.php) প্রতি ১-৫ মিনিটে পেন্ডিং ইভেন্ট প্রসেস করে

সফল উত্তর (200):

{ "ok": true, "message": "ওয়েবহুক গ্রহণ করা হয়েছে (RTN events টেবিলে সেভ হয়েছে)।", "id": 42 }

ত্রুটি - অনুমোদন ব্যর্থ (401):

{ "ok": false, "message": "টোকেন মিলছে না।" }

ত্রুটি - অবৈধ JSON (422):

{ "ok": false, "message": "বৈধ JSON ডেটা পাওয়া যায়নি।" }

⚙️ কনফিগারেশন

১. RTN টোকেন সেট করুন

ফাইল: /var/www/isp_billing/app/config.php

define('BKASH_RTN_WEBHOOK_TOKEN', 'your-secret-token-here-12345');

অথবা Settings টেবিলে সংরক্ষণ করুন।

২. bKash ড্যাশবোর্ডে Webhook URL যোগ করুন

  1. bKash Merchant Dashboard এ লগইন করুন
  2. Settings → Webhooks এ যান
  3. এই URL যোগ করুন: https://YOUR_DOMAIN/api/bkash_rtn/notify.php
  4. টোকেন হেডারে পাঠান: X-Bkash-Webhook-Token: YOUR_TOKEN
  5. ইভেন্ট সিলেক্ট করুন:
    • ✓ Payment Success
    • ✓ Payment Failed
    • ✓ Refund Completed
  6. Test করুন → DB চেক করুন
  7. Save করুন

📈 লেনদেন প্রবাহ

PGW Callback প্রবাহ:

Portal User → Create Payment (bkash_pgw_create.php)
↓
User → bKash Portal (pay)
↓
bKash → Redirect to Callback (GET /api/bkash_pgw_callback.php)
↓
Callback Handler → Execute Payment → Store in sms_inbox
↓
Cron Job (auto_bkash_apply.php) → Match & Apply → Invoice Paid
↓
System Updated (5-10 মিনিটে)

RTN Webhook প্রবাহ:

bKash Payment Occurs
↓
bKash → POST /api/bkash_rtn/notify.php (রিয়েল-টাইম)
↓
Webhook Handler → Validate Token → Parse & Store in bkash_rtn_events
↓
Return 200 JSON Response (বাংলা)
↓
Cron Job (bkash_rtn_process.php) → Process Events → Apply Payments
↓
System Updated (1-5 মিনিটে)

HTTP স্ট্যাটাস কোড

কোড অর্থ বিবরণ
200 OK Webhook সফলভাবে গ্রহণ করা হয়েছে
405 Method Not Allowed শুধুমাত্র POST গ্রহণ করা হয়
401 Unauthorized টোকেন ভুল বা পাওয়া যায়নি
422 Unprocessable Entity JSON পেলোড অবৈধ বা ফাঁকা
500 Internal Server Error ডেটাবেস বা সিস্টেম ত্রুটি

🗄️ ডাটাবেস টেবিল

sms_inbox (PGW পেমেন্ট)

কলাম বিবরণ
gateway 'bkash_webhook'
trx_id bKash Transaction ID
amount পেমেন্ট পরিমাণ
ref_code ইনভয়েস নম্বর
raw_body সম্পূর্ণ JSON রেসপন্স

bkash_rtn_events (RTN ওয়েবহুক)

কলাম বিবরণ
event_hash বিজনতা শনাক্তকরণ (SHA256)
trx_id লেনদেন আইডি
amount পরিমাণ
processed 0=পেন্ডিং, 1=সম্পন্ন
applied_client_id গ্রাহক আইডি (যদি ম্যাচ করা হয়)
raw_body সম্পূর্ণ JSON পেলোড
